# Yasa downloads

[Yasa](https://yasatodo.com) is a to-do app for Windows, macOS and Linux: lists, My Day and Kanban boards, in a
`.yasa` file you own. This repository holds its downloads only: there is no source code here.

Get Yasa from [yasatodo.com](https://yasatodo.com), the [Microsoft Store](https://apps.microsoft.com/detail/9PB134CWRR17)
or the [Mac App Store](https://apps.apple.com/app/yasa-todo/id6825001497), or from the [latest release](https://github.com/pulsar-a/yasa-releases/releases/latest):

| System | File |
|---|---|
| Windows | `Yasa-win-x64-setup.exe` (installs for you), or `Yasa-win-x64.zip` (unpack and run); `-arm64` for ARM |
| macOS | `Yasa.dmg` (Apple silicon and Intel, notarized), or `Yasa-macos-universal.zip` |
| Debian, Ubuntu | `Yasa-linux-x64.deb`: `sudo apt install ./Yasa-linux-x64.deb` |
| Fedora, RHEL | `Yasa-linux-x64.rpm`: import the signing key once with `sudo rpm --import https://github.com/pulsar-a/yasa-releases/releases/latest/download/yasa-rpm-key.asc`, then `sudo dnf install ./Yasa-linux-x64.rpm` |
| Any Linux | `Yasa-linux-x64.tar.gz`: unpack, then `Yasa/install.sh` installs it for you |

The editions from here update themselves when you ask (or at each start, if you turn that on in Settings).

Yasa is free to use but not open source: see the [terms](https://pulsar-a.github.io/documents/yasa/terms/) and the
[privacy policy](https://pulsar-a.github.io/documents/yasa/privacy/). Questions and problems:
[support](https://pulsar-a.github.io/documents/yasa/support/).
